# Hands-on Introduction to Neural Networks Using MNIST

##  Project Overview

This project demonstrates how to build and train a **Neural Network** using the **MNIST handwritten digit dataset**.

The model learns to recognize handwritten digits from **0 to 9** using image data.

##  Dataset

The MNIST dataset contains:

* 70,000 handwritten digit images
* Digits from 0 to 9
* Each image has a size of **28 × 28 pixels**
* Pixel values range from **0 to 255**
* 0 represents black and 255 represents white

The dataset is divided into:

* **60,000 training images**
* **10,000 testing images**

##  Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* TensorFlow
* Keras

##  Project Steps

1. Install and import the required libraries.
2. Load the MNIST dataset.
3. Check the shape and structure of the data.
4. Visualize handwritten digit images.
5. Prepare the data for the neural network.
6. Build a neural network using Keras.
7. Train the model using the training data.
8. Evaluate the model using test data.
9. Check the model's performance.
10. Make predictions on handwritten digits.

##  Neural Network

The project uses a **Sequential Neural Network** with fully connected (`Dense`) layers.

The neural network learns patterns from the pixel values of handwritten digit images and predicts which digit is present.

##  Objective

The main objective of this project is to understand the basic working of **Neural Networks** and apply them to handwritten digit classification using MNIST.
